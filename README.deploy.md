# 🚀 راهنمای جامع بیلد محلی و استقرار خودکار روی سرور (Deploy Guide)

این راهنما ساختار پیاده‌سازی شده برای **بیلد محلی پروژه روی سیستم خودتان (macOS)** و **انتقال به سرور (`192.168.48.151`) با یوزر `root` و اجرای خودکار آن** را تشریح می‌کند.

---

## 📌 چرا بیلد محلی؟ (مزایای این ساختار)
1. **سرعت فوق‌العاده:** فرآیند بیلد فرانت‌اند و کراس‌کامپایل باینری لینوکسی گو روی مک تنها حدود **۴ ثانیه** طول می‌کشد.
2. **عدم وابستگی به اینترنت سرور:** سرور دانشگاه ممکن است محدودیت اینترنت، تحریم داکر، یا سرعت پایینی در دانلود پکیج‌های npm یا go داشته باشد. با این روش هیچ بیلد سنگینی روی سرور انجام نمی‌شود.
3. **عدم تداخل با سیستم لوکال:** باینری لینوکسی به صورت مجزا به نام `backend/server_linux` کامپایل می‌شود تا فایل اجرایی مک لوکال شما (`backend/server`) آسیب نبیند.
4. **محافظت ۱۰۰٪ از اطلاعات حساس سرور:** فایل‌های پایگاه داده (`uisace.db`)، آپلودهای کاربران (`uploads/`) و گواهی‌های دانشگاه (`SSL-Linux/`) به هیچ عنوان رونویسی یا پاک نمی‌شوند، و قبل از راه‌اندازی از دیتابیس بکاپ خودکار گرفته می‌شود.

---

## ⚡ نحوه اجرای استقرار (Quick Start)

### ۱. دستور اجرای مستقیم
هر زمان که مایل بودید تغییرات جدید را بیلد کرده و به سرور بفرستید:

```bash
npm run deploy
```
یا:
```bash
./deploy.sh
```

### ۲. تست بیلد لوکال بدون ارسال به سرور (Dry Run)
اگر می‌خواهید مطمئن شوید فرانت و بک‌اند بدون خطا بیلد می‌شوند اما فعلاً به سرور وصل نشوید:

```bash
npm run deploy:dry
```
یا:
```bash
./deploy.sh --dry-run
```

## 🛠 گزینه‌ها و تنظیمات پیشرفته (CLI Options)

اسکریپت `deploy.sh` از پارامترهای مختلفی پشتیبانی می‌کند:

```bash
# تغییر آی‌پی یا پورت سرور
./deploy.sh --ip 192.168.48.151 --port 22

# مشخص کردن کلید اختصاصی SSH
./deploy.sh --key ~/.ssh/id_ed25519

# فقط ارسال فایل‌ها بدون بیلد مجدد (در صورتی که قبلاً بیلد گرفته‌اید)
./deploy.sh --skip-build

# رد شدن از مرحله تست اولیه پینگ/اتصال SSH
./deploy.sh --skip-ping

# مشاهده تمام گزینه‌ها
./deploy.sh --help
```

## ⚙️ شخصی‌سازی پیش‌فرض‌ها با `.deploy.env`

می‌توانید تنطیمات را در یک فایل ثابت ذخیره کنید تا هر بار نیاز به تایپ پارامترها نباشد:

```bash
cp .deploy.env.example .deploy.env
```
محتوای `.deploy.env`:
```bash
SERVER_IP=192.168.48.151
SERVER_USER=root
SERVER_PORT=22
REMOTE_DIR=/root/UiSaceSite
TARGET_ARCH=amd64
# SSH_KEY=~/.ssh/id_ed25519
```

## 🔄 جریان کار اسکریپت (Architecture Workflow)

```
+-------------------------------------------------------------+
|                     سیستم لوکال شما (Mac)                    |
+-------------------------------------------------------------+
| 1. تست ارتباط SSH با سرور (root@192.168.48.151)              |
| 2. بیلد بهینه React Vite -> ایجاد پوشه dist/                |
| 3. کراس‌کامپایل Go به لینوکس -> backend/server_linux          |
+------------------------------+------------------------------+
                               |
                               | (ارسال فشرده با rsync یا scp)
                               v
+-------------------------------------------------------------+
|                  سرور دانشگاه (192.168.48.151)               |
+-------------------------------------------------------------+
| 4. پشتیبان‌گیری خودکار از پایگاه داده (uisace.db.bak_...)    |
| 5. جایگذاری فایل‌ها در /root/UiSaceSite/                      |
|    - dist/ (فرانت‌اند آماده سرو)                             |
|    - backend/server (باینری لینوکسی)                        |
|    - nginx/default.conf و docker-compose.prod.yml           |
| 6. بالا آوردن مجدد کانتینرها با Docker Compose               |
| 7. تست سلامت نهایی (Health Check)                           |
+-------------------------------------------------------------+
```

## ❓ نکات و عیب‌یابی رایج (Troubleshooting)

### خطای `Operation timed out` در اتصال به SSH:
* آی‌پی `192.168.48.151` یک آی‌پی داخلی در شبکه دانشگاه اصفهان است. مطمئن شوید لپ‌تاپ شما به **اینترنت دانشگاه اصفهان** یا **VPN اختصاصی دانشگاه** متصل است.
* اگر فیلترشکن روی مک فعال است و از حالت کل سیستم (TUN Mode مانند sing-box یا v2rayN) استفاده می‌کند، اطمینان حاصل کنید که رنج `192.168.0.0/16` از تونل بای‌پس شده است یا فیلترشکن مانع پکت‌های محلی نمی‌شود.

### دستورات مانیتورینگ سرور از راه دور:
```bash
# مشاهده وضعیت کانتینرها روی سرور
ssh root@192.168.48.151 "docker compose -f /root/UiSaceSite/docker-compose.prod.yml ps"

# مشاهده لاگ‌های زنده بک‌اند و فرانت
ssh root@192.168.48.151 "cd /root/UiSaceSite && docker compose -f docker-compose.prod.yml logs -f"

# ری‌استارت سرویس‌ها
ssh root@192.168.48.151 "cd /root/UiSaceSite && docker compose -f docker-compose.prod.yml restart"
```
